# itpmo-project-charter-builder

## GitHub Pages

This is a static site and is deployed automatically through GitHub Actions.

1. Open the repository's **Settings > Pages** on GitHub.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push to `main` or run the **Deploy to GitHub Pages** workflow manually.

The published site is available at:

https://rcsrebultan.github.io/itpmo-project-charter-builder/
